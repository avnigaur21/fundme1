npm run install-all       ## first run only
npm run build             ## build frontend for backend/static deployment

## Development: open two terminals in the project root
npm run backend           ## API at http://localhost:5000
npm run frontend          ## React app at http://localhost:3000

## Production-style local run after `npm run build`
npm run server            ## backend serves the build at http://localhost:5000

Before starting, copy `.env.example` to `.env` and
`backend/.env.example` to `backend/.env`, then add your real keys.
Run `backend/supabase/schema.sql` once in the Supabase SQL Editor.
